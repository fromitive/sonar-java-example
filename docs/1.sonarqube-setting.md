### SonarQube 프로젝트 등록

SonarQube 26 버전 기준

1. Projects -> Create a local Project

2. 아래의 양식 작성
```text
* Project display name: repository 이름을 작성하는 것이 좋음
* Project key: repository 이름을 작성하는 것이 좋음. 중복이 없어야함
* Main Branch Name : 메인브랜치가 다를경우 main 브랜치 설정해야함
```

3. Analysis Method 화면에서 CI/CD 선택

CI/CD 선택 가능함. 그렇지만, 연습용으로 "Locally" 선택

4. token 생성

token이 생성될텐데 project 이름으로 기본 생성될것이니 그대로 생성

5. 토큰은 잘 복사한 뒤 보관

6. gradle 설정
```gradle
plugins {
    id("org.sonarqube") version "7.5.0.8588"
}

sonar {
    properties {
        property("sonar.projectKey", "sonar-java-example")
        property("sonar.projectName", "sonar-java-example")
        property("sonar.host.url", "http://localhost:9000")
    }
}
```
plugins는 SonarQube gradle 플러그인이며, 밑 sonar 부분을 넣어야. 해당 프로젝트 대상으로 고정이 된다.

> [!NOTE] 
> gradle에 넣게되면 IDE 에따라 개발환경에도 sonarqube가 다운로드가 된다. 이렇게되면 다른 개발팀이 sonarqube를 불필요하게 다운로드하게 된다. 따라서 다른 개발환경 영향도를 고려해 적용이 필요하다.

7. SonarQube 실행방법

``` bash
SONAR_TOKEN="해당프로젝트의 토큰입력"
./gradlew :build :sonar \
  -Dsonar.token="$SONAR_TOKEN" \
  --info
```
